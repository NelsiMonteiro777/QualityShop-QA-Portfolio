# Exercício de API — Postman Echo

**Objetivo:** praticar o envio de um pedido GET e a leitura da resposta no Postman.

**Método:** GET  
**Endereço:** https://postman-echo.com/get

**Resultado esperado:** receber uma resposta HTTP 200 OK em formato JSON, com o endereço consultado.

**Resultado observado:** a resposta foi 200 OK. O corpo veio em JSON e mostrou o endereço consultado. O campo `args` apareceu vazio porque não foram enviados parâmetros.

**Conclusão:** exercício básico concluído com sucesso.

**Âmbito:** exercício de treino com o Postman Echo; não testa o SauceDemo.
